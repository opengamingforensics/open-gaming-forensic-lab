## 🏛️ 项目定位与架构体系

本仓库为 **开放游戏法医实验室 (OGFL)** 的底层工程代码库与视觉设计规范中枢，包含：

1. **法医级极简视觉规范 (`assets/ui_specs/UI_DESIGN_SPEC.md`)**：
   - 彻底摒弃复古低质 CRT 与廉价手机贴图；
   - 深度深石墨黑基底、60fps 弹簧动力学、激光矢量线条与第四幕和纸良心解药相变系统。
2. **官方证据库网站源码 (`site/`)**：
   - 纯原生法医终端 Web 界面，托管于 Cloudflare Pages 全球 CDN 网络。
3. **案卷发布与生产流水线 (`releases/`)**：
   - EP01-EP03 完整分镜、音频规范、置顶评论、社区帖文案与开源存证索引。
4. **电竞级 8K 视觉资产 (`assets/brand/`)**：
   - 符合 YouTube 官方安全区规范的超清横幅、头像、视频水印与爆款高 CTR 封面。
